# Anticipation study — warning BEFORE the failure starts

> Generated by `python -m src.evaluate_anticipation` — do not edit by hand.

Target: a failure starts within the next *H*. Rows inside a failure and in the hour after it are excluded (ambiguous for this task). Same nested temporal protocol as the main study (outer purged walk-forward, inner leave-one-failure-out, Platt calibration, RN-02 threshold); an alarm counts only if it is persistent (k = 6) and inside [start − H, start). The *detector* rows score the main models (trained on the failure interval) under the same rule, from their saved test scores. Seed 0. Seven failures, six tested: counts, not rates.

*Anticipated* = a persistent alarm inside [start − H, start). *Onset inside window* is stricter: the alarm must switch ON inside the window (an alarm already on before it opened does not show a reaction to the coming failure). *Chance* is the share of random H-long windows of normal operation (≥ 6 h before / 1 h after any failure) that the SAME alarms hit — the rate expected if the model knew nothing about the coming failure (number of reference windows in brackets). Anticipation is evidence only where it clearly exceeds chance.

Per-failure detail is in `models/eval_anticipation.json`.

**Limitation.** With six tested failures, this is exploratory evidence about early warning, not a validation of failure prediction; it complements — does not replace — the main detector results.
