# Classification metrics — every model, leak-free protocol

> Generated by `python -m src.classification_metrics` — do not edit by hand.

Out-of-time evaluation: purged walk-forward (6 folds, each testing a failure unseen by that training), inner leave-one-failure-out selection, 3 seeds (18 runs per model). Confusion counts pooled over the runs. **Accuracy is not informative**: about 98 % of readings are normal, so a model that always says "normal" scores ≈ 0.98 — use balanced accuracy, F2 (recall-weighted, the business priority), MCC and the event metrics.
